APEX LOGISTICS - SECURITY POLICY
Document ID: DOC-POL-002
Version: 1.0 (Effective 2021-06-01, DEPRECATED)
Status: Superceded by Version 2.0

1. Password Standards
All employee account passwords must be at least 8 characters long and changed every 90 days.

2. Multi-Factor Authentication (MFA)
MFA is recommended for remote system access but optional for internal office logins.

3. USB Storage Media
Removable USB storage drives may be used for internal file transfers.
